# SwagDroid — Глубокий ресерч, архитектура и план разработки

> **Концепция**: Универсальный швейцарский нож с открытым исходным кодом для здоровья, безопасности, чистоты, приватности и полного контроля над Android-смартфоном — без рекламы, плацебо-ускорителей и навязанных подписок.

## 1. Честный инженерный разбор: проблема «Лёгкого Root» и её реальное решение

### Почему «Root в 1 клик» в старом понимании больше невозможен
Во времена Android 4–6 приложения вроде *KingRoot*, *Framaroot* или *Towelroot* использовали неисправленные уязвимости ядра Linux (`CVE-2014-3153`, `DirtyCOW`), чтобы тайно перезаписать системный раздел.

В современных **Android 10–16** работают аппаратные механизмы защиты:
1. **Locked Bootloader + Hardware Root of Trust** — процессор проверяет цифровую подпись загрузочного образа ещё до старта ОС.
2. **Android Verified Boot (AVB 2.0) и `dm-verity`** — системные разделы смонтированы только для чтения и проверяются по хэш-дереву на уровне блоков. Любое несанкционированное изменение без разблокировки загрузчика приводит к `bootloop` (кирпичу).
3. Полноценный Root сегодня требует разблокировки загрузчика (с обязательным заводским сбросом данных) и патчинга `boot`/`init_boot` через **Magisk**, **KernelSU** или **APatch**, после чего начинают капризничать банковские приложения, Mir Pay / Google Wallet и госсервисы (из-за *Play Integrity*).

### Инженерный прорыв для SwagDroid: Трёхуровневое ядро привилегий (Zero-PC Escalation)
Обычному пользователю чаще всего нужен не сам факт взломанного загрузчика, а **реальные системные возможности** (удалить мусорные системные приложения, выключить телеметрию, очистить все кэши, поменять скрытые настройки, вылечить баги ОС).

Начиная с Android 11+, в самой системе есть официальный механизм **Беспроводной отладки (Wireless Debugging)**, который позволяет приложению прямо на самом телефоне (без компьютера и проводов!) поднять локальное ADB-соединение и получить права системного пользователя **`UID 2000 (shell)`** — а это **85–90% возможностей рута без потери гарантии, без удаления данных и с полностью рабочими банками и NFC-оплатой!**

Поэтому в основу `:core:privilege` закладывается адаптивная 3-уровневая модель:

| Уровень | Как включается пользователем | Что умеет SwagDroid на этом уровне | Влияние на банки / данные |
| :--- | :--- | :--- | :--- |
| **Tier 1: Базовый (No-Root)** | Обычные разрешения Android (`Storage`, `Usage Stats`, `VPN`) | Сканер APK/майнеров/трекеров, очистка остатков и мессенджеров, локальный VPN-AdBlock + фаервол, базовая диагностика | 100% безопасно |
| **Tier 2: Суперправа без ПК (Built-in Wireless ADB + Shizuku)** | Встроенный визуальный мастер на 45 секунд: ввод 6-значного кода сопряжения прямо в шторке уведомлений (на базе `libadb-android` / `Shizuku`) | Заморозка и удаление системного bloatware, очистка **всех** кэшей одной командой, отключение телеметрии и автозапуска (`AppOps`), твики системы (`Global`/`Secure`), `fstrim`, компиляция `ART`, глубокая диагностика `dumpsys`/`logcat` и программный Фиксер | **Банки и NFC работают, данные не стираются, ПК не нужен** |
| **Tier 3: Полный Root (`libsu`) + Мастер Рута** | Автоподхват `Magisk` / `KernelSU` / `APatch` + встроенный интерактивный **Root Advisor** для тех, кто хочет получить полный Root | Системный `/etc/hosts` AdBlock без VPN-слота, прямой доступ к `/data/data`, управление компонентами (`BroadcastReceiver`/`Service`) внутри чужих приложений, тонкая настройка ядра и батареи | Полный контроль; **Root Advisor** заранее проверяет GKI-совместимость ядра, Knox и даёт чеклист сохранения банков |

## 3. Детальная проработка 5 главных модулей SwagDroid

### Модуль 1: Реальный Антивирус, Анти-майнер и Детектор Скрытых Угроз
Оригинальный `BlendLog/MinerSearch` написан на C# под Windows (сканирует `.exe`, реестр, планировщик задач Windows и WMI). На Android ландшафт реальных угроз другой, поэтому мы переносим **архитектуру принятия решений и карантина MinerSearch**, но строим нативные Android-сканеры:

1. **Сигнатурный офлайн-движок (на базе подходов Hypatia + MalwareBazaar)**:
   - Сверхбыстрое сканирование APK, встроенных `.dex` и `.so` библиотек, а также файлов в `Download` и `/data/local/tmp` по хэшам `SHA-256`/`MD5` через компактные **Bloom-фильтры** (потребляет минимум ОЗУ, работает без отправки личных файлов в облако).
2. **Android Silent Miner & Resource Abuse Scanner (наследник идеи MinerSearch)**:
   - Поиск скрытых ELF-бинарей майнеров (`xmrig`, `minerd`), сигнатур протокола `stratum+tcp://` / `stratum+ssl://`, пулов майнинга и WebAssembly-майнеров.
   - Поведенческий детектор: выявление приложений, которые держат `PARTIAL_WAKE_LOCK` и грузят CPU при **выключенном экране** и зарядке.
3. **Охотник на «Призрачный Adware» (главная реальная зараза на Android!)**:
   - Находит приложения с **прозрачной/пустой иконкой**, со специально скрытой `Launcher Activity`, с поддельными системными названиями (`System Update`, `Google Play Service Helper`, подписанные левым сертификатом), которые выбрасывают полноэкранные рекламные баннеры поверх интерфейса (`SYSTEM_ALERT_WINDOW`).
4. **Детектор банковских троянов и сталкерского ПО (Stalkerware)**:
   - Проверка опасных комбинаций прав у сторонних APK: `AccessibilityService` (чтение экрана и автоклики) + `NotificationListener` (перехват пушей банков) + `READ_SMS` + `DeviceAdmin` (защита от удаления).
5. **Рентген трекеров (Exodus Privacy)**:
   - Показывает, сколько рекламных и аналитических SDK (Facebook, AppsFlyer, AppMetrica, Unity Ads и др.) зашито внутрь каждого приложения.
6. **Менеджер решений и Карантин (как в MinerSearch)**:
   - Для каждой находки понятный вердикт и действия: *Заморозить пакет*, *Отобрать опасные права (Cure)*, *Поместить файл в зашифрованный карантин*, *Удалить*, *Пропустить* — с возможностью восстановления из карантина.

### Модуль 2: Продуманная Очистка Системы (умнее SD Maid SE и честнее CCleaner)
Главный принцип: **никакого обмана вроде «Ускорителя ОЗУ с ракетой»** (принудительное убийство фоновых приложений только сильнее разряжает батарею при их перезапуске). Только честная и безопасная очистка:

1. **Искатель «трупов» (`CorpseFinder`)**: остаточные папки в `Android/data`, `Android/obb`, `sdcard` от давно удалённых игр и программ (со сверкой со списком установленных пакетов).
2. **Умный сейф мессенджеров (Киллер-фича для СНГ!)**:
   - Детальная разборка гигантских папок **Telegram, WhatsApp, VK, TikTok, Viber** по категориям: *видео из каналов, кружочки, голосовые, стикеры, кэш историй* — с предпросмотром, чтобы освободить 20–50 ГБ, случайно не стерев важные семейные переписки и документы.
3. **Очистка системного и скрытого кэша без костылей**:
   - На Tier 2 (Wireless ADB) и Tier 3 (Root) мгновенная очистка кэшей через системные вызовы (`pm trim-caches` / прямая зачистка `cache`/`code_cache`), без медленного перелистывания сотен экранов настроек через Спецвозможности.
4. **Чистка зависших сессий установщика (`Abandoned Install Sessions`) и системных логов**:
   - Малоизвестный факт: прерванные обновления и неудачные установки тяжелых APK оставляют гигабайты «ничейных» файлов в системном staging-разделе (`pm list staging-sessions`). SwagDroid находит и вычищает их, а также `anr`, `tombstones`, `.thumbdata` и остаточные `.apk`.
5. **Умный поиск дубликатов и похожих фото (`SHA-256` + перцептивный `pHash`)**:
   - Находит не только побайтовые копии, но и серии из 5 почти одинаковых кадров или забытые тяжёлые скриншоты, предлагая оставить самый чёткий снимок.

### Модуль 3: AdBlock + Сетевой Фаервол (без вечного конфликта с обычным VPN!)
Главная боль пользователей Android: локальные блокировщики рекламы занимают единственный системный слот VPN и отключаются, как только пользователь включает обычный VPN. SwagDroid решает это **адаптивной 3-режимной схемой**:

1. **Режим Root (Systemless Hosts / nftables)**: монтирует объединённые списки (`AdGuard + OISD + HaGeZi + RU AdList`) на уровне системы. 0% расхода батареи, **слот VPN полностью свободен**.
2. **Режим ADB / Shizuku (Нативный Private DNS DoT + фикс браузеров)**:
   - В 1 клик прописывает зашифрованный DNS-over-TLS с фильтрацией рекламы прямо в `Settings.Global` (`private_dns_mode`) — **не занимает слот VPN и не висит в фоне!**
   - Плюс подсказка/настройка `AsyncDNS` для Chrome/браузеров (чтобы браузер не обходил системную блокировку).
3. **Режим No-Root (Локальный DNS-Sinkhole + Поприложенческий Фаервол)**:
   - Локальный петлевой интерфейс (трафик никуда не уходит, перехватываются только DNS-запросы).
   - **Киллер-дополнение — Интернет-рубильник по приложениям**: запретить офлайн-играм, калькуляторам, фонарикам и галереям выход в сеть → в них физически перестаёт загружаться реклама и сливаться аналитика!

### Модуль 4: Android Optimizer (в духе Windows `Optimizer` + `UAD-ng`)
Чистая панель управления системой без воды, разбитая по понятным вкладкам с бейджами безопасности (`🟢 Рекомендуется`, `🟡 Продвинуто`, `🔴 Только экспертам`):

1. **Умный Debloater и Заморозка приложений**:
   - Интеграция открытой базы знаний **Universal Android Debloater NG** с человеческими описаниями на русском языке: что делает каждый непонятный пакет `com.miui.msa.global`, `com.Daemon`, `com.samsung.android.game.gos`, `com.facebook.system` и безопасно ли его отключать.
   - Поддержка **мягкой заморозки (`Suspend` / `Hide` / `Disable`)** вместо жёсткого удаления, чтобы любое приложение можно было оживить в 1 тап.
2. **Приватность и отключение телеметрии**:
   - Выключение скрытого фонового сканирования Wi-Fi и Bluetooth (даже когда тумблеры Wi-Fi/BT выключены!), сброс/блокировка рекламного ID, отключение системных демонов показа рекламы в прошивках (MIUI/HyperOS, OneUI, RealmeUI/ColorOS), отправка диагностических отчётов.
3. **Производительность, Плавность и Автономность**:
   - **Дробные скорости анимаций** (`0.5x`, `0.75x`, `0.0x`) — смартфон ощущается вдвое отзывчивее без рваных переходов.
   - **ART App Booster** (`cmd package compile -m speed-profile -f -a`) — принудительная перекомпиляция приложений под процессор (аналог фирменной утилиты Samsung *Galaxy App Booster*, но для всех брендов!).
   - Управление **Phantom Process Killer** (снятие лимита на 32 фоновых дочерних процесса в Android 12–16) и **Cached Apps Freezer** (заморозка кэшированных приложений в ядре для экономии заряда).
   - Менеджер **автозапуска (`BOOT_COMPLETED`) и фоновых разрешений (`AppOps`)**.
4. **Пресеты-шаблоны в 1 клик (фишка Windows Optimizer)**:
   - Готовые профили (*«Чистый старт нового телефона»*, *«Максимальная приватность»*, *«Экономия заряда»*) + экспорт и импорт своих настроек в `.json` файл при смене телефона.

### Модуль 5: Программный Фиксер Проблем (`Doctor Engine` + Точки Отката) — Уникальная фича!
То, чего сейчас практически нет на Android в едином и безопасном виде: **полная автоматическая диагностика смартфона + библиотека интерактивных «рецептов лечения» (Playbooks) с гарантированным откатом.**

#### Архитектура безопасности `StateVault` (Транзакционные откаты):
Перед применением **любого** фикса или твика SwagDroid создаёт атомарный снимок состояния (`Snapshot`) в локальной базе: сохраняет старые значения ключей `Settings.Global`/`Secure`/`System`, состояния пакетов, режимы `AppOps` и резервные копии файлов.
- У каждого применённого фикса есть кнопка **«Вернуть как было»**.
- Есть общий **Журнал точек восстановления** (как *Восстановление системы* в Windows) и плитка в шторке быстрых настроек **«Безопасный откат твиков»**.

#### Стартовый каталог проблем и авто-фиксов (разбитый по симптомам «как гуглит человек»):

| Категория | Симптом / Проблема пользователя | Что проверяет Диагност и как лечит Фиксер |
| :--- | :--- | :--- |
| **Сеть и Wi-Fi** | *«Подключено, без доступа к интернету»* (восклицательный знак у Wi-Fi при рабочем интернете — частая проблема в РФ/СНГ из-за сбоев `gstatic`) | Пингует текущие `captive_portal_https_url` и безопасно переключает сервер проверки соединения на доступные зеркала с сохранением дефолта для отката |
| **Сеть и Wi-Fi** | *Не открываются сайты / бесконечная загрузка в общественном Wi-Fi (метро, отели, кафе)* | Детектит конфликт кастомного `Private DNS` со страницей авторизации сети, временно переводит в авто-режим до выхода из публичной сети |

| **Галерея и Файлы** | *В галерее пропали новые фото ИЛИ висят серые битые квадратики давно удалённых картинок* | Очищает битый кэш эскизов и инициирует точечную пересборку индекса `MediaStore` без потери файлов |
| **Система и Тормоза** | *Фризы и долгий запуск приложений после крупного обновления Android* | Проверяет статус компиляции пакетов (`verify`/`quicken`), запускает `speed-profile` оптимизацию и выполняет `sm fstrim` для восстановления скорости флеш-памяти UFS |
| **Экран и UI** | *Сбился масштаб интерфейса, странные цвета экрана, залипла инверсия или ночной фильтр* | Сверяет текущие `wm size`, `wm density`, `accessibility_display_daltonizer_enabled`, оверлеи и возвращает эталонные параметры дисплея матрицы |
| **WebView и Ссылки** | *Приложения вылетают при открытии встроенных страниц или входе в аккаунт* | Проверяет целостность и статус пакета `Android System WebView` / `Chrome`, очищает повреждённый кэш GPU-шейдеров WebView |
| **Bluetooth и Звук** | *Слишком тихий звук или резкие скачки громкости в Bluetooth-наушниках* | Диагностирует конфликт `Bluetooth Absolute Volume` и настроек моно-аудио / лимитера громкости |

## 4. Дополнительные идеи, которые сделают SwagDroid лучшим в классе

1. **Честный Паспорт Железа и Износа (Battery & UFS Health)**:
   - Расчёт **реальной остаточной ёмкости аккумулятора** (сравнение реального счётчика заряда в мкА·ч и циклов перезарядки из `dumpsys battery` с заводским паспортом `power_profile.xml`) + тест скорости чтения/записи накопителя до и после `fstrim`.
2. **Защита буфера обмена (Clipboard Guard)**:
   - На Android многие приложения при открытии незаметно читают буфер обмена (где могут лежать скопированные пароли, номера карт или seed-фразы). Через `AppOps` (`READ_CLIPBOARD = ignore`) SwagDroid может в 1 клик запретить чтение буфера всем приложениям, кроме клавиатуры и менеджера паролей!
3. **Детектор подмены сертификатов и прокси (MITM Check)**:
   - Проверка установленных пользовательских корневых сертификатов (`User CAs`), странных APN и системного прокси — защита от перехвата трафика.
4. **Режим «Перед ремонтом / продажей» и «Чеклист покупки б/у телефона»**:
   - Автоматический тест экрана (битые пиксели, тач, герцовка), датчиков, камер, микрофонов, циклов батареи, статуса загрузчика/рута и региона прошивки — суперинструмент, который прославит приложение!

## 5. Дизайн (UI/UX) и Технологический Стек

### Принципы интерфейса:
- **Jetpack Compose + Material 3 Expressive**: плавная вёрстка, поддержка динамических цветов обоев (Material You) + выверенная тёмная тема для OLED-экранов.
- **Понятность для обычного человека + глубина для гика**:
  - На верхнем уровне — человеческий язык (*«Индекс здоровья: 92/100»*, *«Найдено 3 скрытые проблемы»*, *«Освободить 14.2 ГБ»*), понятные карточки без страшных консольных логов.
  - По нажатию «Подробнее» — полная прозрачность: какой именно системный ключ или пакет затрагивается, почему это безопасно и какой уровень прав (`Базовый` / `ADB` / `Root`) используется.
- **Нижняя навигация из 5 вкладок**:
  1. **Главная (Пульс)** — общий скоринг здоровья, статус прав (`Базовый / ADB / Root`), быстрые карточки и точка отката.
  2. **Защита** — Антивирус / Анти-майнер / Скрытая реклама / Трекеры / Карантин + AdBlock & Фаервол.
  3. **Очистка** — Системный мусор, Хвосты, Сейф мессенджеров, Дубликаты.
  4. **Оптимизатор** — Debloater (`UAD-ng`), Приватность и Телеметрия, Скорость системы, Автозапуск, Пресеты.
  5. **Фиксер (Доктор)** — Полная автопроверка телефона, поиск проблемы по симптомам, рецепты лечения и Журнал откатов (`StateVault`).

### Архитектура проекта (Multi-Module Clean Architecture):
- **Язык**: 100% Kotlin, Coroutines, Flow.
- **DI и хранение**: Hilt, Room (журнал снимков `StateVault`, карантин, кэш сканирования), Proto DataStore.
- **Модули Gradle**:
  - `:app` — навигация, тема, оболочка.
  - `:core:privilege` — единый интерфейс выполнения (`LocalExecutor`, `WirelessAdbShizukuExecutor`, `RootLibsuExecutor`).
  - `:core:vault` — транзакционный движок бэкапа состояний и 1-клик откатов.
  - `:core:designsystem` — UI-компоненты Material 3.
  - `:feature:dashboard`, `:feature:security`, `:feature:cleaner`, `:feature:adblock`, `:feature:optimizer`, `:feature:fixer`.

### Дистрибуция:
Google Play жёстко блокирует настоящие системные AdBlock-инструменты, полноценные очистители (`MANAGE_EXTERNAL_STORAGE`) и менеджеры пакетов (`QUERY_ALL_PACKAGES` / Wireless ADB). Поэтому эталонная стратегия для открытого проекта:
- **GitHub Releases** (с автосборкой APK через GitHub Actions, чтобы любой видел, что APK собран ровно из открытого кода!)
- Поддержка обновлений в 1 клик через **Obtainium** и встроенный апдейтер с GitHub
- Публикация в **IzzyOnDroid** и **F-Droid**

## 6. Поэтапный план реализации (Roadmap)

- **Этап 1 — Фундамент и Ядро Привилегий (Core MVP)**:
  - Инициализация многомодульного Android-проекта (Kotlin + Compose + Material 3 + GitHub Actions CI для сборки APK).
  - Реализация `:core:privilege` (автоопределение прав + интеграция Shizuku / встроенного мастера Wireless ADB + `libsu` для Root + экран диагностики устройства и Root Advisor).
  - Реализация `:core:vault` (движок точек восстановления и откатов с журналом изменений).
  - Главный дашборд с реальным паспортом устройства, износом батареи и статусом привилегий.
- **Этап 2 — Программный Фиксер и Оптимизатор (Главная ценность)**:
  - Запуск первой волны из 15–20 автодиагностик и фиксов с откатом (сеть/Captive Portal, уведомления/Doze, жор батареи, ошибка установки APK, компиляция ART, `fstrim`, масштабирование/анимации).
  - Интеграция Debloater-модуля с локализованной базой `UAD-ng`, заморозкой приложений и тумблерами телеметрии/буфера обмена.
- **Этап 3 — Умная Очистка**:
  - `CorpseFinder`, системный клинер, очистка зависших сессий установщика, очистка кэшей через ADB/Root и модуль бережной очистки Telegram/WhatsApp/TikTok + дедупликатор.
- **Этап 4 — Антивирус / Анти-майнер и 3-режимный AdBlock**:
  - Сигнатурный движок (Bloom-фильтр + хэши), эвристический сканер скрытых рекламных троянов, майнеров, опасных `Accessibility`/`DeviceAdmin` прав, сканер трекеров и менеджер карантина.
  - Адаптивный AdBlock (`Hosts` на Root / `Private DNS DoT` на ADB / локальный `VpnService` + фаервол без рута).
- **Этап 5 — Полировка, Пресеты и Релиз v1.0 на GitHub**:
  - Готовые JSON-пресеты оптимизации, чеклист проверки телефона (экран/сенсоры/батарея), локализация RU/EN, оформление красивого `README.md` и выпуск релиза.

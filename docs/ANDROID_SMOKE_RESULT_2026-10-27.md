2. Сохраняются старые ID, статусы, JSON и исходный повреждённый payload. Legacy/corrupt записи не вызывают executor при попытке отката.

## Как запускались тесты

Gradle собрал main/test APK. После установки в AVD они запускались штатным `androidx.test.runner.AndroidJUnitRunner` через `adb am instrument -w -r`, с явными тестовыми классами.

AGP `connectedDebugAndroidTest` дошёл до работающего эмулятора, но остановился при сетевой загрузке дополнительной host-инфраструктуры. Для исключения этой зависимости изменён способ запуска **тех же instrumentation APK**, а не тестируемая логика и не assertions.

Протокол AndroidJUnitRunner переводится в отдельные XML только при наличии совпадающих start/finish записей всех объявленных тестов и нормального финального кода. Ошибки, crash/abort, незавершённые тесты и пропуски не становятся успехом. Затем CI требует оба модуля и минимум восемь непропущенных тестов.

Действующий `.github/workflows/build.yml` не изменён: дополнительных прав GitHub App не понадобилось. Проверки вызываются существующим workflow через `scripts/ci-build.sh`.

## Исправления инфраструктуры по ходу проверки

Ранние попытки не скрыты и не засчитаны как успешные:

- У SDK tools и Emulator расходились пути поиска AVD. Теперь путь, реальная конфигурация и индекс задаются явно, наличие устройства проверяется до старта.
- Неуспешный информационный `emulator -version` больше не останавливает smoke; headless-зависимости и диагностика запуска заданы явно.
- Изменение `ANDROID_USER_HOME` влияло не только на AVD, но и на debug-keystore. Изоляция оставлена только для emulator/AVD; target и test APK собираются с одной идентичностью подписи.
- Форматы `Signer #1` и `V2 Signer` в `apksigner` обрабатываются проверенным парсером. Android signature check не отключался.
- Для повреждённого сетевого SDK-архива добавлены ограниченные повторы **только установки пакета**. Падающие тесты автоматически не повторяются и не игнорируются.
- Статус внутри кликабельной Compose-карточки читается в unmerged semantics tree, чтобы тест ждал фактический verdict.
